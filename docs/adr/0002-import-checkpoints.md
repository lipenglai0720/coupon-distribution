# ADR：流式文件分发的断点与租约

上传API只保存文件及任务元数据。用户文件名不作为服务器路径；服务器随机命名，支持UTF-8单列CSV及XLSX，最大32MB、一百万条用户记录。
XLSX采用Apache POI SAX事件读取首张工作表的第一列。共享字符串表按POI读取；业务批次只保留500行。

Worker领取60秒租约。每500行在一个MySQL事务内保存收件人、Outbox、错误行及来源行checkpoint，并续租。
重启后从文件开头流式扫描，跳过已提交行；ZIP流不伪装成可随机跳转的文件偏移。
租约owner是写入栅栏，失效Worker不能提交新批次或覆盖新owner。任务/用户唯一键阻止文件重复用户及重放造成重复事件。
解析完成与发券完成分别显示。错误行保留来源行号，业务发券失败保留用户与原因；修复任务从最后提交行继续。

实际验收包含租约切换、旧 Worker 拒绝、文本长 ID、错误行、重复用户，以及 5000 人 Excel 上传并最终发券。
